## 1. Status semantics
- **APPROVED** — explicitly fixed by user instruction or binding authoritative channel requirement; not evidence of creative/technical quality. This status applies only to constraints that were actually approved/required. No V0.3 story, title, art or motion is approved.
- **PROPOSED** — concrete director recommendation, open to user revision; can be discussed and provisionally preflighted only if authorized. No final generation or production lock.
- **REJECTED** — director rejects a V0.1 assumption/creative shortcut as logically or artistically weak, or source/user explicitly disallows it. Where director-origin, not a recorded user rejection; user may authorize a truthful alternative via revision.
- **UNRESOLVED** — decision blocked by evidence, user choice, actual tests, missing files or design. Never default to approved.
- **REQUIRES_ENGINE_PREFLIGHT** — stated creative demand, not verified capability; requires actual operator/producer mapping and evidence prior to final art. Engineering may return refusal, not silently alter creative content.
