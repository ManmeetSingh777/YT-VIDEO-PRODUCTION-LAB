## Execution chain for an unfamiliar script

**Ordering for a film:** direct the explanation first, using the new direction reference's sections 2–6 and 10, and only then use steps 1–6 below to manufacture purpose-built image states. An appealing 2.5D still world is not evidence of a valid visual explanation. Prefer a meaningful changing perspective and a focused causal action to unnecessary visible microdetail. A held background is valid when it makes the causal actor readable; 60fps refers to composited-frame evaluation, not a requirement to animate every drawn object.

**Execution is not evidence by declaration:** a production document that *orders* registered views, source-grounded prompts or iterations does not show they happened. Link each approved view/state to its master, actual provider request/output, edit derivation, measured cross-view anchors, observed comparison and motion consequence. If the trail is absent, the status is `UNVERIFIED_ART_PRODUCTION`, regardless of the quality of the written direction or passing asset hashes. Follow the autonomous loop reference to repair this upstream.

### 1. Separate content from style

New script owns what happens, which novel subjects are present, and what must be communicated. Learned methods own how each part is illustrated and changed. Record: scene goal, original subject list, anatomy, perspective, action/contact, background world, focal hierarchy, alternate drawing states and audiovisual requirements.

### 2. Route each beat, then select transferable construction families

Before designing an artwork, execute F20 and output a `medium_tree`: `WORLD`, `MACRO`, `SCHEMATIC`, `MAP_OR_SCALE`, `PORTAL_OR_SCREEN`, `CINEMATIC_EFFECT`, `EDITORIAL_OR_AD`, with nested nodes when a world contains a diagram, display, or effect. Then **execute F37** and give any world a `world_class` with its own constructor; use F38 for actual projected axes, F39–F45 for class-specific attached partwork, F46 for material-owned light/edges, F47 for density and F48 for whole inner environments. Record the trigger for each medium and intended visual state. Sponsor material is *not* default grammar; use `EDITORIAL_OR_AD` only for genuine editorial need. For nested viewports execute F21/F48 with separate inner/exterior scenes, masks and occluding rim. F22–F36 still govern conditional compositing, diagrams and alternate drawings.

Never use an unrelated frame to assert absent evidence.

### 3. Construct in a fixed dependency order

For each complete subject or environment:

1. **Silhouette:** full purpose-specific outer shape at its actual view and gesture.
2. **Topology:** define named structural parts, parent-child links, joints and purposeful physical contacts.
3. **Depth:** designate visible near/far surfaces, recesses, insertion, overlap, hidden parts and ground/prop support.
4. **Material surfaces:** main contiguous fill + material-local lighter/darker/other-hue planes, attached to the correct anatomy or projection.
5. **Internal construction:** functional controls, eyes/facial features, scales, foliage, reflections, window grids, anatomy, branching networks *only* inside their parent surfaces.
6. **State family:** create complete alternate drawings where view, expression, contact, shape or material state changes; choose rigging only for movements supported by existing drawings.
7. **World coherence:** consistent projection, environmental depth, palette roles, density, lighting ownership and foreground/background contacts.
8. **World-system completeness:** require substrate, class-specific coordinate map, fully connected major parts, locally projected repeat generators, 3-tier density, near/far visibility, material-edge contracts and a 160×90 readability check (F37–F50). A blank gradient and symbols are not a technological environment.
9. **Production medium and visual states:** choose vector, raster-assisted 2D, infographic/code, selective 3D or justified hybrid per visual demand (F19). Materialize a `medium_tree`, named `viewport_layers` and visual `temporal_plates` where changing views/states demand it. **For a still-only job**, finished film direction, transition choreography, audio and editing are not proven by the image; **for a full-film-art job**, execute the complete-film controller above before artwork and pass the designed motion/audio contract to the renderer. Never pretend mute witnesses prove finished motion.

Never try to fix a broken outer form by adding more microtexture. Never use adjective-only commands such as "vibrant," "clean," "rich," "pretty," "fluid," "cinematic" or "high detail" without an immediately linked producing operation.

### 4. Compile, verify source attachments, and submit the actual job

Make an `ArtJob` using [PROMPT_AND_COMPILER.md](references/PROMPT_AND_COMPILER.md). Required fields: original subject/brief; method IDs and precise applicable conditions; exact source witness IDs and contrasting witnesses; structural hierarchy; color-role map; material-local subregions; required view/state variants; spatial contact graph; layer and mask order; environment; special lighting; negatives; unresolved high-impact choices. **When F37–F50 are selected**, `world_system` is mandatory: class, purpose, substrate, coordinate system, region shapes, part graph, connection endpoints, repeat generators, material owners, ordered masks, source-only witnesses, thumbnail/crop tests and original-content noncopy conditions. `scripts/compile_art_job.py` rejects missing world graph structure.

For image production the source-image route is **mandatory**, not optional when an accessible provider permits it: compile `first_pass_control.version=2` using `scripts/prepare_first_pass.py`, verify all witness files exist at native resolution, and use the output request's exact `prompt` and `referenced_image_paths` as the actual image-generation input. Source frames are STYLE ONLY; transmit at least two unlike source witnesses with explicit noncopy roles and one contrast statement. A compiler response means only `COMPILED_WITH_IMAGES_NOT_SUBMITTED`; preserve the actual provider call, generated pixels and first-pass comparison before claiming execution. If references or the provider are inaccessible, report a blocker; do not silently replace the request with prose. If reference-guided generation fails on view consistency, segment and manufacture alternate drawings, masks and clean plates, or use hybrid code/image construction. The studio itself describes its production as vector + pixel-based illustration + infographic and 2D + selective 3D; do not misstate a single universal toolchain as directly observed.

### 5. Run visual and causal evaluation

Review the **whole image** at thumbnail and at native scale, not isolated feature scores. Evaluate separately: silhouette, anatomy/contact, expression, major colored planes, material-specific treatment, environment/subject integration, edge/shadow vocabulary, depth, incidental detail, source-consistent density, whole artistic identity and motion-state readiness.

Try at least two genuinely different unfamiliar briefs, including one **high-density new environment** and one **new abstract/relational world**; separate text-only vs source-witness-guided modes. Use the F50 six-class adversarial matrix before broad claims. Track a canonical character across views if that brief has one; run an ablation removing an actual learned decision to prove it controls output. A single pleasing image is not proof of arbitrary-scene or moving-film generalization.

For failure: state the visible mismatch → identify exact missing/miscompiled choice → query relevant native source/counterexample → revise one operative method/asset/route → rerun original unfamiliar content → compare → preserve result. Do not make scene-specific manual fixes and call them a transferable skill.

### 6. Preserve honest knowledge labels

- `SOURCE_OBSERVED`: directly visible in reference frames.
- `METHOD_CANDIDATE`: generalization proposed from one or more unlike observations.
- `COMPILED`: actually present in a provider/renderer payload.
- `OUTPUT_DEMONSTRATED`: corresponding art seen in actual generated pixels.
- `TRANSFER_TESTED`: multiple dissimilar unfamiliar subjects/states tested.
- `QUALIFIED`: independent blinded quality review + source witnesses + multiple original outputs + causality/ablation + animated state tests passed.

Do not promote all rules to QUALIFIED based on a written guide or structural unit tests.

## Hard rejection conditions

- Copies the scene instead of deriving a conditional style operation.
- Uses a universal palette, stroke thickness, roundness, head ratio, shade amount, camera setting or 3D rig despite contrary source examples.
- Leaves hands/objects/feet disconnected, occlusion false or required alternate pose undrawn.
- Uses arbitrary speckle, symbol stickers, uniform blur, lazy black stroke or generic shape placeholders to imitate complicated subjects.
- Calls an abstract “world” a dark gradient plus free-floating rectangles without explicit physical/relational space, part graph, mask order and source-conditional generator; or mistakes `AI@444`'s light environment for a dark neon realm.
- Claims every frame was understood because a thumbnail sheet exists.
- Compiles a rule but lets actual image request/renderer ignore it.
- Calls a single static sample an audiovisual or arbitrary-script qualification.
