# From script to video: the actual execution chain, and how it compares with the original neutrino film

Every claim below is tagged with its evidence class:
- **[STATIC]**: read in the published source only.
- **[DIAG-EXEC]**: executed on labelled diagnostic fixtures, either in rehearsal K (`hybrid_v2/work/p02/rehearsal_K/`, run `DIAG-20261122142022-e1cc63`, hash chain verified, 214 events) or in a named test, whose result is in `hybrid_v2/work/audit_logs/*.txt`.
- **[UNPROVEN-GPT]**: has never run with genuine GPT-created artwork. **No GPT artwork has ever entered this system.**

Files cited are in this repository. Reachability comes from `analysis/PRODUCTION_REACHABILITY.json`.

## Part 3: what the next task must establish (not done here)

To make the original's acting quality operate on **registered GPT art**, the current system lacks four things:
- **(a)** An art-driven equivalent of `S.actor` secondary motion: breath, blink and idle sway on registered parts, successive-breaking lag, and springs.
- **(b)** Face and mouth state cels with timing.
- **(c)** A render-path consumer for phrases (overlap/settle), contact squash and cast shadows.
- **(d)** A music/SFX/loudness stage.

None of these is speculative-repaired here; this document only fixes the starting point.
