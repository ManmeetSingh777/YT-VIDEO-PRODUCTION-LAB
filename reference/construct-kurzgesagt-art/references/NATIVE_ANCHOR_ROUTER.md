# Portable original-resolution style-only witness router

The guide packages 19 hand-selected **native source-film JPEG witnesses** under `assets/molecular_native_anchors/` as a practical bridge for a **new chat or different image provider**. These are *small reference images from the user's supplied reference videos*, provided **only** to infer conditional drawing construction. They are **not** subject libraries, ready-to-use source characters, asset plates, backgrounds, architectural templates, world layouts, logos, or source footage to reproduce. Do not trace/copy their objects or feed them as edit targets when creating new scripts.

The previous 85 question-driven timestamps are also available as eight smaller cross-reference boards in `assets/abstract_world_witnesses/` and the `QUESTION_WITNESS_MANIFEST.json`. The 19 anchors are selected for **high molecular readability at original source dimensions**, not because 19 scenes stand for all 242,095 frames; the other 66 temporal strips and 60 high-change contact frames remain distinct evidence groups. The volcano film is a **sixth supplemental source**, never included in the five-film frame count.

## How to use with a provider

1. Decide the new script's *causal world class* and actual subjects before choosing source files. Select 1–2 witnesses for the relevant producer and **at least one unlike counterreference**. Four style-only images is usually enough for a single new world; more may cause unintentional subject leakage rather than greater control.
2. Label **every** source attachment: `STYLE ONLY: take plane/shading/projection/connection grammar; do not depict its objects, layout, identity, specific colors as fixed brand tokens or original narrative`.
3. Attach the new filled `ArtJob`/compiled request with actual novel objects, region masks and relationships. If the provider has a length limit, select only directly applicable rules; a 19-image montage and a 50-rule unfiltered prompt are not necessary for every scene.
4. Inspect the image at native size and thumbnail, then write an explicit **source-conditional comparison**, not “looks close.” Example: “New lab's tube tip has no port while `AI_0514` shows a port; add a separate front socket ring on the actual new device without borrowing source cube shape.”
5. For view/state consistency, preserve the newly generated master image and edit that target while using film images only as style references. A source still is **not** the edit target for an unfamiliar script.

The 19 anchors are not an official Kurzgesagt style library and do not grant use of source characters, imagery or intellectual property outside the user's own reference analysis. Keep original art content novel. Each requested output must stand on the new script's design, not the anchor's subject.
