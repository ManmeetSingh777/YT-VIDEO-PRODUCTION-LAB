## Reproduce the film

**Requirements:**
- Windows or macOS/Linux with Node ≥ 22;
- Python 3.11+ with numpy and Pillow;
- FFmpeg;
- internet access for `npx hyperframes@0.9.11` on first use, which downloads the CLI and its headless Chrome.

```bash
cd source
# 1) regenerate derived files (optional: they are already present, and regenerate byte-identically)
python tools/timing.py
python tools/mkscenes.py
python tools/audio.py
node tools/build.mjs
# 2) check and render
npx hyperframes@0.9.11 check --json
npx hyperframes@0.9.11 render -o final_raw.mp4 --crf 20      # ~6 min for 120 s on the original machine
# 3) audio loudness post (as delivered): two-pass loudnorm, video copied
ffmpeg -i final_raw.mp4 -af loudnorm=I=-16:TP=-1.5:LRA=9:print_format=json -f null -
ffmpeg -i final_raw.mp4 -c:v copy -af "loudnorm=I=-16:TP=-1.5:LRA=9:measured_I=<..>:measured_TP=<..>:measured_LRA=<..>:measured_thresh=<..>:offset=<..>:linear=true,aresample=48000" -c:a aac -b:a 192k -movflags +faststart final.mp4
```

The original measured values were `measured_I=-18.92`, `measured_TP=-2.30`, `measured_LRA=2.50`, `measured_thresh=-28.99`, `offset=0.28`.

**Only to re-synthesize the voice** (not needed, and not guaranteed identical):

```bash
python -m venv kokoro-venv
kokoro-venv/Scripts/python -m pip install kokoro-onnx==0.4.7 onnxruntime==1.31.1 soundfile
set HYPERFRAMES_PYTHON=<path>/kokoro-venv/Scripts/python.exe
npx hyperframes@0.9.11 tts "<sentence>" -v af_heart -o assets/audio/vo/sN.wav     # s1–s6 used -s 1.05
```

## What has been verified (see `evidence/REBUILD_VERIFICATION.md`)
- Every generated file (timing, scene manifest, audio stems, 12 HTML files) regenerates **byte-identically** from this source.
- Three 1-second spans re-rendered from the regenerated source match `final.mp4`:
  - PSNR 39.8–42.0 dB, SSIM 0.963–0.976, frame-aligned;
  - the differences are lossy-encoding noise only.
- **A full 120-second clean rebuild has not been demonstrated.**
- **Voice re-synthesis has not been tested.**

## Known reproduction risks
- **HyperFrames:** the version is pinned (0.9.11) but fetched from npm; a removed version would break rendering. The exact GSAP build is archived in `vendor/`.
- **Headless Chrome:** its SVG rasterisation and font rendering may differ slightly on other versions or machines.
- **Kokoro model:** the hash is recorded in `environment_versions.txt`, but the model is not included (325 MB, re-downloadable).
- **HTML files are generated:** edit `tools/*.mjs`, never `compositions/*.html`, or the next build overwrites your change.

## Not included (reinstallable or bulky caches)
- `node_modules`, the npx cache, the Kokoro venv and model;
- `.hyperframes/` snapshot PNGs (252 MB; contact sheets are kept in `evidence/snapshot_sheets/`);
- the Studio thumbnail cache (`.thumbnails/`).
